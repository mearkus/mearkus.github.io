# mearkus.github.io

Personal landing page, served at [mearkus.com](https://mearkus.com).

## Adding a project

1. Add a 960×540 hero image (JPG, or SVG for non-visual tools) to `assets/projects/`.
2. Copy one of the `<li class="project">` cards in `index.html` and update the
   link, image, name, blurb, tags and source link.
